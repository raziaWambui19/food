# Recipe Website 

## overview
a simple, interactive recipe website where users can:

-View existing recipes.
-Add new recipes with image, ingredients, and descriptions.
- see newly added recipes automatically appear on the recipes page.

Built with ** HTML, CSS, and JavaScript**, using **localStorage** to save recipes locally in the browser.


---

## pages

| page | Description |
|------|-------------|
| **Home (`index.html`)** | welcome page.|
| ** Recipes (`recipes.html`)** | view all recipes, including dynamically added one. |
| ** Add Recipes (`add-recipes.html`)** | Add a recipe with name, description, image, ingredients, and accompaniments.

---


## Features

- Responsive navigation menu 
- Dynamic recipe display with Javascript
- Recipes save in browser `localStorage`
- Image encoded in Base64 for local use

---


## How to run 

1. Clone or download the repository.
2. Open `index,html` in web browser.
3. Navigate throught the menu.
4. Add recipes via `add-recipe.html` and see them appear on `recipes.html`.

---

## Technologies Used

- **HTML5** - Page structure
- **CSS3** - Styling & layout 
- **JavaScript** - Dynamic functionality & local storage
